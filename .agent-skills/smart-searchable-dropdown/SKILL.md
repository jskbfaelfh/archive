# مهارة القوائم المنسدلة الذكية القابلة للبحث (Smart Searchable Dropdown List)

## 1. فلسفة المهارة والهدف المعماري
تهدف هذه المهارة إلى توفير تجربة مستخدم (UX) فائقة السلاسة والسرعة عند التعامل مع القوائم المنسدلة عبر كافة شاشات ونوافذ النظام، بحيث تتحول القائمة تلقائياً وديناميكياً إلى قائمة قابلة للبحث المباشر الفوري (**Searchable Dropdown**) عندما يتجاوز عدد عناصرها حداً معيناً، مع البقاء كقائمة منسدلة اعتيادية بسيطة وسريعة إذا كان عدد العناصر صغيراً، ودون أي تشويه أو تغيير في الهوية البصرية الموحدة للنظام.

---

## 2. القاعدة الحتمية لمعيار التحول الذكي (Adaptive Threshold Rule)
- **الحد المعياري الصارم (Threshold > 10):**
  - **إذا كان عدد الخيارات أكثر من 10 عناصر (`options.length > 10`):**
    - تتحول القائمة تلقائياً إلى **Smart Searchable Dropdown**.
    - يظهر حقل بحث مدمج في أعلى القائمة (`sticky top-0`) مع أيقونة البحث (`Search` من `lucide-react`).
    - يتم التركيز التلقائي (`autoFocus`) على حقل البحث فور فتح القائمة لتمكين المستخدم من الكتابة مباشرة.
    - تصفية فورية وسريعة باللغتين العربية والإنجليزية غير حساسة لحالة الأحرف (`case-insensitive`).
    - عرض رسالة راقية "لا توجد نتائج مطابقة" (`text-[13px] text-slate-400 text-center py-4`) عند عدم العثور على نتائج.
  - **إذا كان عدد الخيارات 10 عناصر أو أقل (`options.length <= 10`):**
    - تظل القائمة منسدلة قياسية اعتيادية **دون إظهار حقل البحث نهائياً**.
    - لا يوجد أي شريط إضافي أو تعقيد بصري، مع الحفاظ على سرعة وسلاسة الاختيار المباشر.

---

## 3. معايير التصميم البصري الصارمة (Zero Visual Disruption)
يُحظر تماماً التلاعب بالتصميم البصري أو كسر قواعد التصميم المعتمدة في النظام:
1. **الالتحام وانعدام الفجوة (Seamless Radius Fusion - Rule 30 & 32):**
   - عند فتح القائمة للأسفل: يكون زر التفعيل بحواف علوية مستديرة وسفلية حادة (`rounded-t-[7px] rounded-b-none`)، وتلتحم القائمة المنسدلة معه بحواف علوية حادة وسفلية مستديرة (`rounded-t-none rounded-b-[7px]`).
   - عند فتح القائمة للأعلى: تنعكس الحواف بدقة متناهية (`rounded-t-none rounded-b-[7px]` للزر، و`rounded-t-[7px] rounded-b-none` للقائمة).
2. **الطبقة المعلقة العلوية عبر React Portal (Rule 32):**
   - تُعرض القائمة المنسدلة دائماً عبر `createPortal` مباشرة في `document.body` مع `z-index: 99999` وموضع ثابت (`position: fixed`).
   - يمنع تماماً قص القائمة أو إخفاؤها داخل حاويات `overflow-hidden` أو المودالات.
   - خلفية بيضاء نقية (`bg-white dark:bg-slate-900`) وظلال عميقة (`shadow-2xl`) بدون أي إطار خارجي (`border-none`).
3. **حقل البحث المدمج الأنيق (Search Box Specs):**
   - مثبت بأعلى القائمة: `sticky top-0 z-10 bg-white dark:bg-slate-900 border-b border-slate-100 dark:border-slate-800 p-1.5`.
   - حجم الخط: **13px حتماً (`text-[13px]`)** وفق القاعدة 12.
   - حواف الإدخال: `rounded-[5px]`.
   - أيقونة البحث: `w-3.5 h-3.5 text-slate-400` في بداية الحقل (`absolute start-2.5`).
4. **شريط الحالة الإلزامية (Dynamic Start Border - Rule 29):**
   - حقل الاختيار يدعم الحد الأولي الملون 3px (`border-s-[3px] border-s-rose-500` إذا كان مطلوباً وفارغاً، و`border-s-emerald-500` عند امتلائه) دون وضع نجمة (`*`).

## 4. البنية الهندسية وتطبيق المهارة على مستوى النظام
- **المكون المركزي الموحد:**
  - يتم تطبيق المهارة مركزياً داخل المكون العام `src/components/common/Select.tsx` ومساعده `src/components/common/SelectMenuPortal.tsx`.
  - نظراً لأن كافة شاشات ونماذج النظام (المقررات، التدريسيون، القاعات، الجداول، الكليات، الإعدادات، الفلاتر) تستخدم هذا المكون حصراً، فإن أي شاشة تستفيد تلقائياً من المهارة فوراً.
- **التوافق وسقف الأسطر:**
  - الالتزام الصارم بسقف الـ 300 سطر للملف الواحد (`npm run check:lines`).
  - عزل لوحة الخيارات المعلقة في `SelectMenuPortal.tsx` للحفاظ على نظافة وهيكلية الكود.

---

## 5. التفاعل ولوحة المفاتيح (Keyboard & Accessibility)
- **Escape:** إغلاق القائمة فوراً وإعادة التركيز.
- **Backspace / Typing:** تصفية فورية للقائمة دون تأخير.
- **إعادة التعيين:** مسح نص البحث تلقائياً عند إغلاق القائمة أو إعادة فتحها.
